Limitations

  • Scope: four numbers only (MSE and MAE on ETTh1, horizon 96, with lookback 336 and 720). This is not a check of the whole paper.
  • Single run per setting on CPU with the repository's default seed (2024) and the paper's 30 epochs. No variance estimate, so small differences are within normal run-to-run noise.
  • Measured values are 0.0% to 1.9% from the claimed ones; 'reproduced' means within 2%.
  • The baselines used for 'still beats the paper's reported baselines' are the numbers printed in the paper, not re-run by Crucible.
  • The run was driven by an automated agent using a free open model (minimax/minimax-m3.1-flash:free). It did not edit the authors' model or evaluation code, but its final commands add two inline compatibility shims: np.Inf = np.inf (NumPy 2) and forcing torch.load to map_location=cpu.
  • Not replay-verified: the recorded Dockerfile contains only setup steps (clone, data download) and not the training, so 'crucible rerun' cannot yet reproduce these numbers from a fresh container. A replayable re-run is planned.
